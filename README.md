# Práctica D2 - Juego de adivinar el número

## Descripción
Programa en Python que genera un número aleatorio entre 1 y 100.
El usuario debe intentar adivinarlo en un máximo de 10 intentos.

## Funcionamiento
- Genera un número aleatorio.
- Solicita números al usuario.
- Indica si el número buscado es mayor o menor.
- Controla las entradas incorrectas mediante try/except.
- Permite jugar varias partidas.
- Registra las partidas jugadas y ganadas.

## Funciones
- pedir_numero(): solicita y valida un número.
- jugar_partida(): desarrolla una partida.
- preguntar_repetir(): pregunta si se desea jugar otra vez.
- main(): controla el programa y las estadísticas.
